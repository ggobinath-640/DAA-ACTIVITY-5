ACTIVITY 5

This activity covers five classic algorithmic problems using Java, recursion, and backtracking.

01. Subsets
LeetCode:[78 – Subsets](https://leetcode.com/problems/subsets/)

Generates the power set of a given integer array using recursive backtracking. Each element is considered for inclusion or exclusion to produce all possible subsets.

02. Permutations
LeetCode:[46 – Permutations](https://leetcode.com/problems/permutations/)

Generates all possible arrangements of distinct integers using backtracking. A boolean array tracks visited elements to ensure that each element appears exactly once in each permutation.

03. Combination Sum
LeetCode:[39 – Combination Sum](https://leetcode.com/problems/combination-sum/)

Finds all unique combinations of candidate numbers that sum to a specified target. Backtracking explores valid combinations while allowing each candidate to be reused.

04. N-Queens
LeetCode:[51 – N-Queens](https://leetcode.com/problems/n-queens/)

Places N queens on an N × N chessboard so that no two queens attack each other. Backtracking validates column and diagonal constraints and reverses invalid placements.

05. Sudoku Solver
LeetCode:[37 – Sudoku Solver](https://leetcode.com/problems/sudoku-solver/)

Solves a 9 × 9 Sudoku puzzle using recursive backtracking. Each empty cell is assigned a valid digit while satisfying row, column, and 3 × 3 subgrid constraints.


Technical Stack

- Language: Java
- Core Concepts: Recursion and Backtracking
- Data Structures: Arrays, Lists, and Boolean Arrays
- Platform: LeetCode

 Learning Objectives

- Develop a strong understanding of recursive problem-solving.
- Apply backtracking to combinatorial and constraint-satisfaction problems.
- Implement systematic search and state restoration.
- Improve algorithm design and problem-solving skills.

 Execution

Each solution is implemented as an independent Java program. Compile and execute the required class using the Java Development Kit (JDK).

Example:

```bash
javac Subsets.java
java Subsets
```
